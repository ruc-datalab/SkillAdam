## ALFWorld-specific guidance

The public skill format remains exactly `## Workflow` followed by
`## Error Avoidance`. Generalize from repeated goal parsing, systematic
search, exact-object selection, transformation, delivery, progress tracking,
and loop-recovery patterns.

Do not preserve case IDs, game file paths, raw observation dumps, literal
object/receptacle instance numbers, gold actions, evaluator thresholds,
provider details, or benchmark bookkeeping in the skill.
