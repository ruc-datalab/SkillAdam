# ALFWorld Skill Writing Policy

- Keep exactly `## Workflow` and `## Error Avoidance`.
- Preserve workflow order: parse, search, acquire, transform, deliver, verify.
- Prefer operational guidance grounded in repeated trajectory evidence.
- Revise weak guidance before adding an overlapping rule.
- Never include case IDs, game paths, raw observations, literal instance
  numbers, gold actions, provider details, metrics, or gate thresholds.
- Reusable task types, object-location priors, action sequencing, and
  loop-recovery rules are allowed when they transfer across episodes.
